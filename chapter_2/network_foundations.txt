#Communications Models

We access systems through their address. The problem is that each system will have multiple address. These addresses are best separated into buckets
related to the functionality provided by the protocol each address belongs to.

##Protocols

A protocol is a set of rules or conventions that dictate communication.

##OSI

It includes seven layers. Messages start being created from the Application layer down.

- Application (layer 7): The application layer is the one closest to the end user. This does not mean that it is the application itself, however.
Application layer protocols manage the communication needs of the application. They may identify resources and manage interacting with those
resources. As an example, the HTTP is an application layer protocol. It takes care of negotiating for resources btw client and the server.
- Presentation (layer 6): It's responsible for preparing data for the application layer. It makes sure that the data that is handed up to the
application is in the rght format so it can be consumed.
- Session (layer 5): It manages the communication btw the endpoints when it comes to maintaining the communication of the applications (client and
server). Remote procedure calls (RPCs) are an example of a function at the session layer. There are components of file sharing that also live at
the session layer, since negotiation of communication btw the endpoints needs to take place. It takes care of making sure that files are succesfully
transmitted and complete.
- Transport (layer 4): It takes care of segmenting messages for transmission. It also takes care of multiplexing of the communication. Both the TCP
and the UDP are transport protocols. These protocols use ports for addressing, so receiving systems know which application to pass the traffic to.
- Network (layer 3): It gets message from one endpoint to another. It does this by taking care of addressing and routing. IP is one protocol that
operates at this layer.
- Data Link (layer 2): One other address to contend with is the media access control (MAC) address. This is layer 2 address, identifying the
network interface on the network so communications can get from one system to another on the local network. The Address Resolution Protocol (ARP),
virtual local area networks (VLANs), Ethernet and Frame Relay are Data Link layer protocols. They take care of formatting the data to be sent out on
the transmission medium.
- Physical (layer 1): This is all the protocols that manage the physical communications. 10BaseT, 10Base2, 100BaseTX and 1000BseT are examples of
physical layer protocols. They dictate how the pulses on the wire are handled.

One of the problems with the OSI model is that there are not always good fit when it comes to mapping protocols to the seven layers. The problem
often comes in the areas btw the Session and Application layers. As an example, at which layer does does the Secure Shell (SSH) protocol live?
Is it the Session layer because it ultimately manages sessions, or is it the Presentation layer because it includes encryption mechanisms and
negotiates them? Other protocols seem to exist btw layers. ARP, for instance, is said to to operate at the Data Link layer, but it needs to know
about the network layer because it provides the bridge btw the addressing in those two layers.

However, there are places where having the model makes conceptualizing things much easier.
